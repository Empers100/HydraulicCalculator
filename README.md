# Гидравлический калькулятор / Hydraulic Calculator / 液压管道计算器

[![GitHub Pages]( https://github.com/Empers100/HydraulicCalculator/)

Инженерный гидравлический калькулятор для расчёта трубопроводов с поддержкой **сжимаемости**, **криогенных жидкостей** и **смесей СПГ**. Работает полностью в браузере, без сервера.

## Что умеет

- Расчёт скорости, перепада давления, числа Рейнольдса и коэффициента трения для труб
- Упрощённый и инженерный режимы
- Учёт сжимаемости газа (M > 0.3 Маха)
- Поддержка 20+ индивидуальных веществ (воздух, азот, метан, аммиак, водород, гелий, неон, аргон, ксенон, фреоны и др.)
- **СПГ/ПГ (LNG/NG)**: смесь с настраиваемыми долями метана, этана, пропана, бутанов, изопентана и азота
- Автоматическое определение фазового состояния (жидкость/газ/сверхкритика) для чистых веществ и смеси
- Индикатор достоверности модели (зелёный/жёлтый/красный)
- Локализация: русский, английский, китайский
- Тёмная тема
- Сохранение отчёта в файл
- APK для Android (PWA)

## Технические детали

- Уравнение состояния: **Пенг-Робинсон с α-функцией Тву (PR‑Twu)**
- Вязкость газа: **Jossi‑Stiel‑Thodos** с поправкой на давление
- Плотность жидкости: **Rackett**, для квантовых жидкостей (He, H₂) – таблицы насыщения
- Скорость звука и поправка на сжимаемость: изотермическая модель идеального газа
- Смеси (СПГ/ПГ): псевдокритические параметры по правилу Кея, плотность по COSTALD
- Фазовое равновесие СПГ: через интерполяционное уравнение Антуана для псевдокомпонента
- Границы применимости для каждого вещества

## Ограничения и точность

| Вещество / Условия | Погрешность плотности | Примечание |
|-------------------|----------------------|------------|
| Неполярные газы (N₂, O₂, CH₄) | < 2% | PR‑Twu точен |
| Полярные (NH₃) | 5–10% | Вблизи критической точки |
| Квантовые (H₂, He) | 10–30% при T < 50 K | Требуются квантовые поправки |
| Сжиженный газ (жидкая фаза) | 5–10% | Rackett/COSTALD – оценочно |
| Смеси СПГ | 5–10% | Правило Кея упрощённое |
| Критическая область | > 10% | PR‑Twu некорректен |

Для проектирования: сверяйте с **NIST REFPROP**.
